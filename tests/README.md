# تست‌های بک‌اند

| دستور | چه می‌کند | نیاز |
|---|---|---|
| `npm test` | ۶۷ تست واحد (بدون DB/شبکه؛ یکی‌شان یک درخواست واقعی به api.github.com می‌زند و بدون شبکه skip می‌شود) | فقط `npm install` |
| `TEST_MONGO_URI=... npm run test:integration` | ۶۹ تست یکپارچه روی **دیتابیس واقعی**: سیاست نشست‌ها (دستگاه تازه محدود، تأیید از دستگاه قدیمی)، نگهداری جدای هر نوع رسانه (موسیقی/ویس/فایل)، فوروارد (نام فرستنده/پنهان‌سازی/کانال/بلاک E2E)، نقل‌قول بخشی از پیام، «چه کسانی خواندند» + حریم رسید، حریم افزودن به گروه، مزاحم نشوید (گیت پوش)، جستجوی GIF، همگام‌سازی تنظیمات (زبان/قفل/ترجمه با مهر زمانی؛ رازها ذخیره نمی‌شوند)، محافظت محتوا (فقط مالک، رد فوروارد)، ربات inline (commands/webhook، timeout، امنیت، «via»)، چت مخفی (تایمر از خواندنِ گیرنده حتی با رسید خاموش، پیام سرویس تایمر/اسکرین‌شات، محدودیت نرخ)، پاک‌سازی داده/ربات/حساب، و **مسیر ارسال پیام با سرور سوکت واقعی و کلاینت واقعی** (متن، تصویر، فایل، ویس، پیام ویدیویی، استیکر، E2E، زمان‌بندی، تاپیک، ریپلای، تکراری‌ها، ورودی خراب، مسابقه‌ی لحظه‌ی اتصال) | یک سرور سازگار با MongoDB |

## داشتن یک دیتابیس برای تست
1. **mongod محلی** (ساده‌ترین): `TEST_MONGO_URI=mongodb://127.0.0.1:27017 npm run test:integration`
2. **mongodb-memory-server** (اگر `TEST_MONGO_URI` نباشد خودکار): نیاز به دانلود باینری mongod از اینترنت.
3. **FerretDB** (تک‌فایل، بدون نصب؛ همان چیزی که در ساخت این تست‌ها استفاده شد):
   ```bash
   curl -L -o ferretdb https://github.com/FerretDB/FerretDB/releases/download/v1.24.0/ferretdb-linux-amd64 && chmod +x ferretdb
   ./ferretdb --handler=sqlite --sqlite-url=file:./data/ --listen-addr=127.0.0.1:27017 --telemetry=disable &
   TEST_MONGO_URI=mongodb://127.0.0.1:27017 npm run test:integration
   ```
   ⚠️ FerretDB 1.x دو محدودیت دارد که تست‌ها خودشان تشخیص می‌دهند و فقط همان ادعا را رد می‌کنند: `$pull` با شرط روی زیرسند (بی‌صدا نادیده گرفته می‌شود) و `partialFilterExpression` (ساخت ایندکس شکست می‌خورد). روی **MongoDB واقعی/Atlas** هر دو کار می‌کنند؛ برای اطمینان کامل یک‌بار روی mongod واقعی اجرا کنید.
   ⚠️ هر اجرا از دیتابیسی با نام یکتا استفاده می‌کند و آخرش آن را حذف می‌کند.

## چه باگ‌هایی را همین تست‌ها گرفتند
- ایندکس `unique+sparse` با مقدار `null` (`User.phoneHash`/`telegramId` و `Chat.inviteCode`/`publicUsername`): **فقط یک چت/کاربرِ بی‌شماره** در DB تازه می‌توانست وجود داشته باشد.
- **مسابقه‌ی ثبت هندلر سوکت:** پیامِ لحظه‌ی (باز)اتصال بی‌ack دور ریخته می‌شد (= «پیام یک‌بار خطا می‌دهد، با لمس می‌رود»).
- `getSettings()` با دو upsert هم‌زمان E11000 می‌داد و احراز هویت سوکت را می‌کشت.
- توکن موقت 2FA به‌عنوان توکن کامل پذیرفته می‌شد؛ sanitizerها شیء را به `[object Object]` تبدیل می‌کردند؛ `BlockList` همه‌ی IPv4 عمومی را مسدود می‌کرد.
